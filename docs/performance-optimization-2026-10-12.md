# 2026-10-12 当前更新的性能优化与发布验收

## 基准和范围

基准是 10 月 12 日用户更新后的本地网站，不是旧提交的外观。保留导航、联系方式、两张经历卡片、鸣鸣很忙的曲面截图带与章节动效、镜前时代的新现场场景以及兴趣页的新照片和文案。不改 CSS 视觉规则、3D 轨道参数、视频、原图或业务数据，不新增依赖。正式网站继续使用 EdgeOne，两个视频继续使用原有香港 COS。

## 实施

- 两个案例改为分别加载其代码和 CSS；把邻近照片预载 hook 移到真实页面挂载后运行，避免外层懒加载组件还没出现时提前查找空 DOM。
- 素材带在生产环境不再逐帧生成详细 JSON 投影和 DOM 调试记录；开发模式仍保留诊断。渲染、纹理、曲面、自动运动速度、惯性、拖动、键盘、弹窗与暂停逻辑不变。
- 新增 20 张 800px、质量 92 的 WebP 展示副本，使用 `srcset`/`sizes` 按真实显示宽度和设备像素密度选择；保留每张原图、完整比例、色彩和文字说明。只有已生成的副本进入响应式清单，新路径自动使用原图，不猜测不存在的副本。
- 导航 PNG 转为无损 WebP，保留 1254×1254 尺寸。自动比较每个可见 RGB 像素及全部 alpha 值，完全一致，SVG 的蒙版和动画不变。

## 可核实的体积变化

| 项目 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 当前兴趣照片原图集合 / 800px 选择集合 | 6,202,586 B | 3,796,844 B（减少 39%） |
| 导航图像 | 715,164 B | 414,176 B（无损，减少 42%） |
| 案例公共入口 JS | 203.94 KB | 2.36 KB，随后仅加载选中案例 |
| 鸣鸣很忙 JS（含本次拆分的共用依赖，不含原本共用的首页运行时） | 约 204 KB | 约 130 KB |
| 案例样式 | 两个案例共 117.36 KB | 鸣鸣 85.08 KB / 镜前 32.28 KB |

照片集合的 39% 不是所有设备的总流量下降；大画幅、高 DPR 仍可选择原图。拆分后的 JS 不能只统计单个 55KB 页面而漏算 71KB 共用库。首页 JS 约 368KB、3D 包约 893KB 均保持原有规模。

本机进行了前后帧采样，但自动滚动/焦点带来的采样位置不完全一致，不能据此宣传帧率或 CPU 下降百分比。此次主要可证实的收益是传输量下降、案例隔离和删除详细逐帧调试工作，而非承诺任何网络都秒开。

## 验收

- TypeScript、Vite、首页预渲染通过；静态首页仍保留 200 个当前简介字符、32 张画廊节点和六个详情入口，首屏滚动恢复保护及 reduced-motion 回退通过。
- 188 个实际本地素材路径检查通过，20 张新副本及无损导航图存在。原图未删除、未覆盖。
- 素材带专项：投影、完整比例、回环、命中原图、与已批准 demo 相同的惯性、鼠标/触摸逻辑、空闲/隐藏/离屏暂停、reduced motion、WebGL 与监听器清理通过；新增生产环境不输出详细帧诊断的测试通过。
- 与已有素材带源码逐行对比，仅允许诊断 guard 的变化；实际渲染、纹理、输入和自动运动算法完全一致。
- 六个详情页在 1440×900 下的标题、正文、图片 alt 与尺寸及两个视频地址/封面与本轮基准逐项一致。
- 390×844 下逐段检查六页：无横向溢出、无已请求图片加载错误、无新增控制台错误；运动 6 张、旅行 13 张、用户更新后的唱歌 2 张、读书 7 张均保留且加载成功。
- 镜前时代证据分类与翻页通过；未打开的证据轮播页仍按需请求，不误报为丢失素材。鸣鸣九张不同原图可在大图中逐一切换，Escape 关闭正常；训练营可切到第二张，运营工具及 RPA 图片实际加载成功。
- 首页刷新从 scrollY 0 开始；手机导航“履历”、案例返回、兴趣入口及返回位置正常；桌面 3D Claude 详情通过键盘打开并关闭。
- Impeccable 检测针对本轮修改的界面文件返回空问题列表；React 检查关注懒加载、hook 挂载时机和保持键盘/语义控制。

仍有既有 Three.js `THREE.Clock` 弃用警告和 >500KB 的 3D 构建提示，不以隐藏警告或删除效果消除。旧 `check-mingming-block-motion`/`check-mingming-transitions` 脚本含旧设计整文件哈希锁，用户更新后的 globals.css 已不匹配；没有改旧基准或跳过锁来宣称通过，采用本轮功能与内容实测及专门的素材带等价检查。

本轮原始截图和检查 JSON 位于本地 Codex visualizations 的 `perf-20261012`，不发布到站点。
