# 镜前时代 · 滚动场景研究与制作依据

后续内容微调说明：本研究保留此前动效观察与过程证据。当前页已按最新指令取消原图查看，恢复原有图片尺寸与轮播；素材分配、留资口径和本次验收见 [素材分配清单](D:/噜噜/作品/docs/hengqian-material-allocation.md)。下文原图交互记录属于此前阶段。

研究日期：2026-10-10。参考：[Stanzza / awards](https://stanzza.design/awards)。该地址实际显示室内设计首页。桌面 1440×900、手机 390×844；实际内容宽度分别为 1425、375px（含浏览器滚动条）。全部观察先于本轮主要动画代码修改。

## 证据与判断方法

浏览器执行重载、小步滚动、大步滚动、停下、反向、悬停、菜单点击、项目箭头点击和手机图片拖动；记录截图、真实时间戳、滚动位置、元素矩形、computed transform / opacity / position。755 张过程帧与原始记录在 [motion-study 目录](D:/噜噜/作品/artifacts/hengqian-redesign/motion-study/)。完整机器记录：[reference-states.json](D:/噜噜/作品/artifacts/hengqian-redesign/motion-study/reference-states.json)、[交互记录](D:/噜噜/作品/artifacts/hengqian-redesign/motion-study/reference-interactions.json)。文件名中的数字是实际采集顺序，不是视频帧率。

将滚动与时间分开判断：滚动位置停稳后仍继续出现的字形属于时间播放；随滚动位置连续变化、反向又回到先前位置的图片矩阵属于滚动控制。computed `position:sticky`、恒定的屏幕位置与明确释放点共同证明固定机制。没有读取站点内部时间线对象，以下时长和缓动若未经直接测量均标为估计。

工具没有录屏接口，只能交付连续关键帧与操作记录。这种证据不能完整证明时序、帧率与流畅度，也不能据此给出还原百分比。

## 1. 首次载入、首屏入场与离场

位置：`#hero`，完成载入后约一屏高。桌面先看到由照片组成的加载画面，随后主摄影展开、标题逐字出现，说明随后建立。首屏摄影占全视口，标题居下方中央。手机摄影保留主视觉，标题与说明纵向重排，底部调用按钮出现。

状态：首次采样中主标题容器 opacity:0、y:27px；在约 2.6 秒采样期间还未完成。后续观察到摄影容器成为 100svw×100svh、主图 scale:1.25、全部标题字形出现。加载总时间受网络、预加载与动画共同影响，本次证据不能将其断言为固定 2.6 秒。进入视口后的字形由 `translateY(20%)` / opacity:0 变为正常；估计字形运动约 0.6–1 秒，逐字错峰。

离场：普通页面滚动将摄影带离视口，米白章节接续。小步滚动时，加载阶段输入曾不改变 scrollY，完成后滚动才生效；这说明参考有加载阶段的限制。本页不复制等待期间阻塞滚动的行为。重载会重新播放加载/文字阶段；返回首屏后字形保持已揭示。

证据：`013–057-desktop-first-entry-*`、`058–092-hero-slow-down-*`、`384–401-return-top-fast-*`；手机 `443–497-mobile-load-*`、`498–518-mobile-composition-slow-*`、`726–745-mobile-return-top-*`。

本页实现：现有 Framer Motion 控制首屏字形/两行副标题的蒙版入场和按钮错峰；照片先建立较窄画窗，再展开。GSAP 仅控制首屏外围组的滚动离场，文字子节点的入场 transform 由 Framer Motion 独占。立即提供阅读入口，不设置加载锁。

位置：`#composition`。稳定布局中顶约 900px、高 1800px。它不是五张图片统一 fade-in：中央标题单独 sticky，图片分布在一块两屏高的相对定位画布中，随正常文档滚动依次经过视口；图片内部还有滚动视差。

| 固定与发展 | scrollY≈1042–1978；标题 y 恒为 89.77；图片先中央，再左上/右侧，再左下/右下，视觉密度变化 |

标题：横向居中，字体约 50px，标题本身 `position:sticky; top:89.78px`，不是整个桌面画布 pin。左右段落分别使用 sticky，top≈143.64px。标题/段落字形是进入视口后按时间揭示，完成后反向滚动不会重新透明；图像内部运动可逆。参考某些阶段文字直接压在照片上，本页保留中央阅读区，避免中文与人脸相互遮挡。

反向证据：从2212反向到1279时，第一图内部位移回到约−112.5px，与正向1275时−111.9px相近；差值包含浏览器平滑滚动尚未完全停稳。最后停稳1278，第一图−112.25px。快滚从1278到2898直接跨入绿区，标题正常释放，未观察到中央场景按时间继续锁住用户。

## 3. 手机米白场景：固定整块内容、滚动驱动横向摄影

手机发生了机制变化。`#composition` 高2532px（3×844）；标题本身 position:relative，整块 `.content_composition` sticky、top:−32px，高≈744px。标题停留在屏幕 y≈32，两个段落在上方连续阅读，下方是横向摄影条。

五张图片同为约281px宽，间隔约8px；滚动进度使整个条带从首图 x16 移到约−1071。例如 scrollY1077，首图x3、次图x292；1347时首图x−193、次图x95；1889时第三图x−18、第四图x270；2427时第五图x165。不是用户必须在嵌套容器里横向滚动。反向至1587，第三图回到x200，标题和文字位置不变。快滚进入绿区后整块释放。

内部图像从y0到约−115.7px，随后保持终态。标题文字揭示仍按时间完成，不因反向重播。没有在手机上观察到桌面那种散落的五图布局。

关键帧：518（进入）、525/532/539（横向发展）、560（尾图）、572（反向）、594（释放到绿区）。本页采用同样的“普通纵向滚动驱动摄影条横移”机制，四张图、90px左侧图标安全区。固定区域缩短到约3屏，始终提供“阅读数据”跳转；减少运动模式取消固定与横移，四张图正常流式展示。

## 4. 橄榄绿项目区：中央图扩展、信息转位、释放与切换

位置：`#apartment`，稳定桌面顶2700px、高3150px（3.5屏），`.content.is-apart` sticky top0、高900px。

| 阶段 | 桌面实际状态 |
|---|---|
| 入场和停留 | scrollY≈2898–3309；中央摄影926×585、约65%视口宽高，x249/y157；标题在左，信息在右，按钮在图下；该尺寸有明确停留区间 |
| 扩展 | scrollY3724时965×610；4138时1198×756；4552时1398×883；标题和信息从各自向内/上方的偏移回到另一组位置 |
| 占满 | scrollY≈4967，图片1425×900；标题/信息转到图片之上，按钮也同步进入图片下部 |
| 释放 | 之后固定容器 y 开始为负；scrollY5379时y−433，米白的下一章进入 |

这是滚动控制的尺寸与位置变化，不是进入视口后播放一次缩放。反向会改变初始项目的扩展尺寸。但一旦项目轮播启用，活动项目与初始扩展节点并不总相同，不能只读第一张图片的矩阵来断言当前可见项目。实际点击右箭头观察到画面和标题从 Valencia 转为 Jazean，伴随图像分区/横向转场、项目信息和计数同步。短时停下未证明固定周期的自动轮播；不声称存在某个 autoplay 时长。

手机绿区仍固定约一屏；图片先约95%视口宽、半屏高，逐步升至接近整屏高。标题由上方进入，信息先位于图片下方，之后叠入下部。桌面左右箭头在手机 display:none，实际点击被工具拒绝；尝试拖动图片未在连续帧中确认项目切换，故移动端切换手势尚未得到验证。本页使用明确的44px摄影切换按钮，不复制不可验证的手机控制。

## 6. 导航与交互

桌面菜单悬停：文字两行分别y−14.12、−16.12px，图标scale0.85。点击后实际观察到约299px宽的米白菜单、导航和联系信息；关闭为同按钮。摄影卡片悬停后遮层opacity0→1，内部视差矩阵基本不变，说明悬停与滚动各控制不同节点。项目按钮采用描边/底色与文字翻动；链接指向真实页面或锚点。

证据：402–407菜单悬停、408–419展开、435–442摄影悬停及交互JSON。手机菜单点击后本会话未取得持续展开画面，记录为未验证，不用桌面成功替代手机结论。

本页：共享导航保留；本页链接做文字蒙版/箭头反馈，图片入口可键盘操作；Tabs共享布局指示线和原图弹层继续使用已核对的 Aceternity 模式与现有 Framer Motion。动画只作为状态反馈，原生dialog的焦点锁、关闭、原始像素和恢复焦点继续有效。

### 代表场景的开始、发展、停留与退出

### 保留的差异和原因

参考桌面纸区两屏、五张大小不一的室内图，本页2.7屏、四张真实制作摄影；中文短文集中在标题下方，摄影避开阅读区。标题top130而非参考约90，是为共享左上图标留边。参考绿图扩展到浏览器边缘，本页扩展到左右安全内容边界，1440下最大1185px宽；这落实用户批注中的正文边距。

手机参考绿图扩展至整屏高，本页限制31%→43%屏高，并保留标题与说明的独立空间。265px安全宽度下，将横幅采集摄影拉到844px高会严重裁掉人物和设备；本页保留可辨认的真人与采集场景。手机最主要的空间运动由前段四图横移承担。该差异在对照图中明确可见，不称作完全一致。

参考项目切换观察到分区／横向的图像转场，本页两张采集摄影使用整幅垂直蒙版切换，不复制多项目的标题与信息替换，因为两张图属于同一个AI项目。它保留主动切换与计数同步，转场轨迹存在可见差异。

没有复刻参考加载锁、室内项目名称、不可验证的手机项目手势或自动轮播。未测量设备FPS、长任务及实际触屏硬件上的耗电表现；浏览器操作与连续截图可发现明显断层、错误固定和空白，但不能证明所有设备无持续掉帧。
